# 指标、验证与上线边界

## 区分每一步

页面访问 → 资料/咨询入口点击 → 提交尝试 → 服务端确认保存 → 业务查看与判定 → 人工触达 → 人工回复 → 报价/样品/试单 → 订单。

- 按钮点击不是询盘；保存成功不等于通知成功。
- 文件下载不是有效客户；测试记录不得进入有效线索。
- 自动回复、退信与人工回应分别记录。
- 同一企业多个联系人、多个需求与多个订单分开建模，不能混为客户数。

## 建议观察（尚非实际运营结果）

| 指标 | 口径与前提 |
| --- | --- |
| 保存成功率 | 相同观察期内确认保存 / 合法提交尝试，按提交ID去重 |
| 业务有效率 | 同批截至日已认定有效 / 已完成人工判定；报告待判定数量 |
| 人工回复率 | 同批有效且已触达线索中的人工回复 / 同批有效且已触达；排除自动回复与退信 |
| 渠道成本 | 同一渠道和同批线索的可归集成本 / 对应结果；未知成本不写0 |
| 成交与贡献 | 成熟批次及明确订单证据；成本与收入同币种、同口径 |

这些是评估建议，公开仓库没有实现分析平台、广告投放或生产CRM。原项目既有Excel/SQL是另有版本边界的指标演示，未作为真实运营数据迁入。

## 证据等级

1. 原项目历史本地验收记录支持页面与交互实现规模；不提供线上商业结论。
2. 原项目18项测试在2026-10-15评估时重跑通过，覆盖询盘、内容、多语和TDS部分规则。
3. 本仓库精选模块测试验证抽取后的规则；模拟接收回执仅验证分支，不证明外部服务已配置。
4. 真实用户任务测试、生产收件联调、访问性能、询盘及订单归因尚需另行完成。

公开材料不包含公司原始验收截图或业务资料，外部读者可复验公开代码，无法独立复验全部本地业务站。

## 最小上线检查

正式域名与HTTPS；接收端可靠保存、持久化去重、限流、通知失败补偿；真实负责人能查到请求；私有文件与密钥管理；正式内容与多语审核；数据处理告知和留存规则；目标市场访问与手机任务实测。预览默认不开放索引，正式索引配置另行验收。

AI客服不在现有上线能力中。SEO结构、Schema和内容就绪不能推导出排名提升或生成式搜索引用保证。
