# Industrial B2B Website
### 工业品海外获客站：买方路径与可靠询盘

[English case study](docs/case-study.en.md) · [中文案例](docs/case-study.md) · [证据索引](docs/evidence-map.md)

围绕海外买方“判断供应商—查找材料—比较资料—发起咨询”的任务组织网站，并把产品、语言和来源带到统一的收件流程。

作者：**Zegang Cui**。工作包括需求与资料输入、范围讨论、业务判断、多轮评审与推进；AI 工具辅助代码和文档实现。

## 一次提交，何时才算成功？

使用Node.js 22.6+，无第三方依赖，无需安装包：

~~~sh
npm run demo
npm test
~~~

| 离线模拟情况 | 演示结果 | 解释 |
| --- | --- | --- |
| 未配置接收服务 | 失败，且不调用接收端 | 避免界面假报成功 |
| HTTP 200，没有匹配保存回执 | 失败 | 传输成功不等于可靠保存 |
| stored=true，且提交ID匹配 | 成功 | 只验证回执分支；不发送真实邮件或保存到销售系统 |

样本使用虚构买方与内存响应。精选模块还验证TDS短期签名、本地幂等保存与生产环境禁用本地模式。没有真实PDF或生产凭证；测试成功不能代替生产联调。
